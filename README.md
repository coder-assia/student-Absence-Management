#  Gestion des Absences

Projet de gestion des absences développé en binôme avec :

- Frontend : React JS + Tailwind CSS
- Backend : Spring Boot
- Base de données : MySQL
- Authentification : JWT

---

#  Fonctionnalités

##  Admin
- Gestion des étudiants
- Gestion des enseignants
- Gestion des modules
- Gestion des absences

##  Enseignant
- Ajouter des absences
- Modifier des absences
- Consulter les classes

##  Étudiant
- Voir ses absences
- Consulter ses modules

---

#  Technologies

- React JS
- Tailwind CSS
- Spring Boot
- Spring Security
- JWT
- MySQL

---

#  Installation

## Backend

```bash
cd backend
mvn spring-boot:run
````

Backend lancé sur :

```bash
http://localhost:8082
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend lancé sur :

```bash
http://localhost:5173
```
